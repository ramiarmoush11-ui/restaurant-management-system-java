# Restaurant Management System

A Java Swing desktop application for managing restaurant meals, orders, customers, employees, and daily reports.

## Features

- Graphical User Interface built with Java Swing
- Customer and employee management
- Manager and employee authentication with different permissions
- Add, edit, and remove meals
- Display available meals with images and details
- Create and manage customer orders
- Support for dine-in, delivery, and special orders
- Cash and credit card payment options
- Order status updates using multithreading
- Store completed orders in a text file
- Generate daily restaurant reports
- Track daily orders and revenue
- Identify the most ordered meal
- Identify the most frequent customer

## Application Structure

The application provides different interfaces for customers, employees, and managers.

Managers can manage meals, view current orders, and access reports, while regular employees have limited access to the system.

## Technologies

- Java
- Java Swing
- Object-Oriented Programming
- Multithreading
- File Handling
- Java Collections
